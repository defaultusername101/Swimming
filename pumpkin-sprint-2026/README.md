# Pumpkin Sprint Meet — November 7–8, 2026

[Open the meet app](https://defaultusername101.github.io/Swimming/pumpkin-sprint-2026/)

Interactive, mobile-friendly heat sheets for Saturday and Sunday. Search and filter by swimmer, heat, lane and event; enter result times, places and notes. Includes original PDFs. Results are stored in your **device’s browser local storage**, not on GitHub; use the app's backup/export controls for a copy.

**Privacy:** The site is in a public GitHub repository and includes the full meet heat sheets, including minor swimmers’ names and ages. The actual typed-in results remain private to the browser unless exported or shared.

**To use on iPhone:** Open the app in Safari and select Share → Add to Home Screen.

**Meet:** Saturday warmups begin at 9:00 AM for visiting teams; first Saturday event is at 10:30 AM. Sunday first event 10:00 AM.
